% Abstract (Do not insert blank lines, i.e. \\) 
\abstract{In this paper, we describe the two related scripting methods of cartographic data processing and visualization that provide 2D and 3D mapping of Japan with different algorithm complexity. The first algorithm utilizes Generic Mapping Toolset (GMT) known as an advanced console-based program for spatial data processing. The modules of GMT combine the functionality of scripting with the aspects of geoinformatics which is especially effective for rapid analysis of large geospatial datasets, multi-format data processing and mapping in 2D and 3D modes. The second algorithm presents the use of the R programming language for cartographic visualization and spatial analysis. This R method utilizes the packages ‘tmap’, ‘raster’, ‘maps’, ‘mapdata’ to model the geomorphometric elements of the Japanese archipelago, such as slope, aspect, hillshade and elevation. The general purpose graphical package ‘ggplot2’ of R was used for mapping prefectures of Japan. The two scripting approaches demonstrated an established correspondence between the programming languages and cartography, which is determined with the use of scripts for data processing. They outperform several well-known and state-of-the-art GIS methods for mapping due to high automation of data processing. Cartography has largely reflected recent advances in data science, rapid development of scripting languages and transfer in the approaches of data processing. This extends to the shift from the traditional GIS to programming languages. As a response to these new challenges, we demonstrated in this paper the advantages of using scripts in mapping, which consist in repeatability and flexible applicability of scripts in similar works. The graphical plotting in 2D and 3D modes is performed in RStudio and GMT.}
